Interview Simulation Portal - Minimal PHP + MySQL scaffold
Files:
- config.php      : DB connection (update credentials)
- init.sql        : SQL to create database and tables
- index.php       : Landing page
- signup.php      : User registration
- login.php       : User login
- logout.php      : Logout
- header.php      : Common header
- footer.php      : Common footer
- assets/style.css: Simple styles
- admin/dashboard.php
- admin/create_interview.php
- admin/add_question.php
- candidate/dashboard.php
- take_interview.php
- submit_answers.php
- feedback.php

Instructions:
1. Place the folder in your PHP server (e.g., XAMPP htdocs).
2. Create a MySQL database (name: interview_portal) and update config.php with DB credentials.
3. Run the SQL in init.sql to create tables.
4. Open site in browser and register/login.

This is a minimal starting point. Expand as needed.
